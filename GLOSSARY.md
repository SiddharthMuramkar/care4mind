# Care4Mind

The new care4mind.org, a portal for Indian psychology. This file names the words the project uses, so people and agents mean the same thing by them. A word starts with who it belongs to: `dev-` for the developer, `user-` for the person taking a Questionnaire, and `client-` for the Client.

## Language

**Client**:
Care4Mind, the organisation the site is built for and handed over to.
_Avoid_: customer, owner

**Questionnaire**:
A set of questions with documented scoring rules that gives the person answering a result.
_Avoid_: assessment, quiz, test

**dev-session**:
A Claude Code working session in which the developer decides and works.
_Avoid_: session (on its own)

**user**:
The person who signs up and takes a Questionnaire.
_Avoid_: participant, respondent

**user-session**:
The period a user is logged in to the site.
_Avoid_: session (on its own)

**emailed code**:
The six-digit code a user types to confirm their email when they sign up or log in.
_Avoid_: OTP, magic code, password

**bot check**:
The test every sign-up and log-in must pass to show a real person is behind it.
_Avoid_: captcha, verification

**user-report**:
The PDF a user gets after finishing a Questionnaire, which analyses each of their answers.
_Avoid_: report (on its own), result PDF

**client-reviewer**:
Someone at the Client who can read every user's results.
_Avoid_: reviewer, admin

**client-lecture**:
A talk the Client gives, after which the Client shares the site with those who attended.
_Avoid_: lecture, session

**client-dashboard**:
The private page where a client-reviewer finds users by name and opens their results.
_Avoid_: admin panel, dashboard (on its own)

## Pictures

**Emblem**:
The Care4Mind logo picture: a pink lotus whose petals form a brain.
_Avoid_: logo image

**Sticker**:
A small folk-art icon with a cream die-cut edge, showing one central symbol.
_Avoid_: icon, badge

**Pothi**:
A Sticker of a palm-leaf manuscript, one for each Traditional text.
_Avoid_: cover, book cover

**Plate**:
A square Indian folk painting, whether the client's own or made for this site.
_Avoid_: photo, illustration, hero image, scene

**Medallion**:
The way a Plate is shown: cropped to a circle inside a drawn ring. It is not a kind of picture.
_Avoid_: round image, circle

**Frontispiece**:
The Medallion at the head of a topic page.
_Avoid_: banner, hero

**Ornament**:
A border or frame drawn in code rather than kept as a picture file.
_Avoid_: divider image

**Interim picture**:
A stand-in shown at the head of a page until that page's own picture exists.
_Avoid_: placeholder, fallback
