## Question

How does each content type link to the others? FR-01 rests on this.

For each pair of types, decide:

- one way or both
- typed or plain
- one or many
- whether each link carries a short note on why it's there
- whether reverse links appear automatically

Then decide what a Concept page's related set contains, and in what order. Every related Concept, traditional text, application, Reference and Questionnaire must be one click away.

Decide how a link between a Concept and a modern psychological construct is recorded, so it is never an automatic equivalence:

- whether the construct is its own record or a label
- the allowed relation types (for example "compared with", "partly overlaps")
- a required explanation and supporting References
- how the link is shown

Keep it separate from an English gloss in a title.

Draw the result as an entity diagram in the answer. The developer decides the structure; the relation types go to the Research editor in the sign-off pack.
